IMPORT APRES INSTALLATION
-------------------------
1. Ouvre SOPHENIC.
2. Ouvre « Fournisseurs IA ».
3. Clique « Importer TXT ».
4. Selectionne ton fichier de cles.
5. SOPHENIC chiffre localement les cles avec Electron safeStorage/Windows.
6. Verifie le nombre de cles detectees.
7. Supprime ensuite le TXT en clair.

IMPORTANT
---------
Le TXT de cles n'est volontairement pas inclus dans ce ZIP et aucune cle n'est inscrite dans le code ou dans l'EXE.
Comme les cles ont ete partagees dans une conversation, il est recommande de les regenerer apres validation du systeme puis de reimporter le nouveau TXT localement.

Cloudflare : chaque token conserve son propre Account ID.
Scaleway : la Secret Key sert aux appels d'inference ; l'Access Key ID reste une metadata locale.

Voir docs/SOPHENIC-API-IMPORT.md pour les details.

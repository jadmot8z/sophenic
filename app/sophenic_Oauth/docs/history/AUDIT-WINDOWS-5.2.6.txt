LIMITATION DE CET ENVIRONNEMENT
Le conteneur de correction est Linux et ne contient ni Wine ni NSIS Windows. Le build NSIS final et les tests GUI Windows sont donc exécutés par build-sophenic.ps1 sur la machine Windows de build. Le script refuse le résultat si les contrôles runtime/ICU/package échouent.
